# GINETEX Care Symbols

Accessible, framework-agnostic packages for the **GINETEX / ISO 3758** laundry care symbols.

## What are the GINETEX care symbols?

The GINETEX care symbols, standardised as ISO 3758, are the pictograms on textile care labels. They
are always listed in the same order: washing, bleaching, drying, ironing and professional care.
Dots indicate temperature; one bar under a symbol means a mild process, two bars a very mild one;
a cross means the treatment is not allowed.

| Category | Symbols | Base shape | Covers |
| -------- | ------- | ---------- | ------ |
| `washing` | 9 | Wash tub | Maximum temperature, mild / very mild process, hand wash |
| `bleaching` | 5 | Triangle | Any bleach, oxygen / non-chlorine only, do not bleach |
| `drying` | 12 | Square | Tumble drying (dots = heat) and natural drying (line, flat, drip, shade) |
| `ironing` | 5 | Iron | Maximum soleplate temperature (dots = heat) |
| `professional-care` | 12 | Circle | Professional dry cleaning (P, F solvents) and wet cleaning (W) |

## Quick start

### React

```sh
npm install @ginetex/react
```

```tsx
import { SymbolById } from '@ginetex/react';

<SymbolById id="wash-30" width={64} />
```

Named components are also generated for each symbol:

```tsx
import { Wash30, DoNotTumbleDry } from '@ginetex/react';

<Wash30 width={64} />
<DoNotTumbleDry width={64} title="Do not tumble dry" />
```

### Vue 3

```sh
npm install @ginetex/vue
```

```vue
<script setup>
import { SymbolById } from '@ginetex/vue';
</script>
<template>
  <SymbolById id="wash-30" :width="64" />
</template>
```

### Web Components

```sh
npm install @ginetex/elements
```

```ts
import { defineCustomElements } from '@ginetex/elements';
defineCustomElements();
```

```html
<ginetex-symbol symbol-id="wash-30" width="64"></ginetex-symbol>
<ginetex-wash-30 width="64"></ginetex-wash-30>
```

### CSS sprite (no JavaScript)

```sh
npm install @ginetex/css
```

```js
import '@ginetex/css/sprite.css';
```

```html
<span class="ginetex-wash-30" style="display:inline-block;width:64px;height:64px"
      role="img" aria-label="Wash at or below 30 °C"></span>
```

### SVG sprite

```sh
npm install @ginetex/sprite
```

```html
<svg width="64" height="64" role="img" aria-label="Wash at or below 30 °C">
  <title>Wash at or below 30 °C</title>
  <use href="/path/to/sprite.svg#wash-30" />
</svg>
```

### Programmatic API

```ts
import { getAllSymbols, getSymbol, getSymbolsByCategory } from '@ginetex/core';

const allSymbols = getAllSymbols();                        // CareSymbol[]
const symbol     = getSymbol('wash-30');        // CareSymbol | undefined
const drying = getSymbolsByCategory('drying');         // CareSymbol[]
```
