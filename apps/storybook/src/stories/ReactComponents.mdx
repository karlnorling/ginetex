# React Components

Inline SVG components for all laundry care symbols. Each component is tree-shakeable, fully accessible, and accepts the same `SymbolProps` interface.

## Installation

```sh
npm install @ginetex/react
```

## Basic usage

Named components are generated by `yarn generate` after running `yarn update`:

```tsx
import { Wash30, DoNotTumbleDry } from '@ginetex/react';

export default function CareLabel() {
  return <Wash30 width={120} />;
}
```

## Dynamic rendering by ID

```tsx
import { SymbolById } from '@ginetex/react';

<SymbolById id="wash-30" width={120} />
```

## Props reference — `SymbolProps`

<Canvas of={ReactStories.Wash30} />
<Controls of={ReactStories.Wash30} />

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `width` | `number \| string` | SVG intrinsic width | Width of the `<svg>` element |
| `height` | `number \| string` | SVG intrinsic height | Height of the `<svg>` element |
| `title` | `string` | Symbol name | Accessible title (`<title>` inside SVG) |
| `description` | `string` | Symbol description | Accessible description (`<desc>` inside SVG) |
| `className` | `string` | — | CSS class on the root `<span>` wrapper |
| `style` | `React.CSSProperties` | — | Inline styles on the root `<span>` wrapper |
