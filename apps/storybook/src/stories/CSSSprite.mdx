# CSS Sprite

Import `sprite.css` to get a set of `.ginetex-*` utility classes. Apply a class to any block element sized with `width`/`height` — no JavaScript required.

## Installation

```sh
npm install @ginetex/css
```

## Setup

```js
import '@ginetex/css/sprite.css';
```

```css
@import '@ginetex/css/sprite.css';
```

## Usage

```html
<span
  class="ginetex-wash-30"
  style="display:inline-block; width:64px; height:64px"
  role="img"
  aria-label="Wash at or below 30 °C"
></span>
```

### CSS helper

```ts
import { getCssClassName } from '@ginetex/css';

const cls = getCssClassName('wash-30'); // → 'ginetex-wash-30'
element.className = cls;
```

---

## Class name pattern

Classes follow the pattern `ginetex-{code}` — e.g. `ginetex-wash-30`, `ginetex-iron`, `ginetex-do-not-bleach`.
