## Installation

Pick the package for your framework:

<Tabs>
  <TabItem label="React">
    ```sh
    npm install @ginetex/react
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```sh
    npm install @ginetex/vue
    ```
  </TabItem>
  <TabItem label="Web Components">
    ```sh
    npm install @ginetex/elements
    ```
  </TabItem>
  <TabItem label="CSS">
    ```sh
    npm install @ginetex/css
    ```
  </TabItem>
</Tabs>

## Quick start

<Tabs>
  <TabItem label="React">
    ```tsx
    import { Wash30, SymbolById } from '@ginetex/react';

    // Named component
    <Wash30 width={64} />

    // Dynamic by ID
    <SymbolById id="wash-30" width={64} />
    ```
  </TabItem>
  <TabItem label="Vue 3">
    ```vue
    <script setup>
    import { Wash30, SymbolById } from '@ginetex/vue';
    </script>

    <template>
      <!-- Named component -->
      <Wash30 :width="64" />

      <!-- Dynamic by ID -->
      <SymbolById id="wash-30" :width="64" />
    </template>
    ```
  </TabItem>
  <TabItem label="Web Components">
    ```ts
    import { defineCustomElements } from '@ginetex/elements';
    defineCustomElements();
    ```

    ```html
    <!-- Generic element -->
    <ginetex-symbol symbol-id="wash-30" width="64"></ginetex-symbol>

    <!-- Named element -->
    <ginetex-wash-30 width="64"></ginetex-wash-30>
    ```
  </TabItem>
  <TabItem label="CSS">
    ```js
    import '@ginetex/css/sprite.css';
    ```

    ```html
    <span
      class="ginetex-wash-30"
      style="display:inline-block;width:64px;height:64px"
      role="img"
      aria-label="Wash at or below 30 °C"
    ></span>
    ```
  </TabItem>
</Tabs>

## Finding symbol IDs

Every symbol has a stable kebab-case slug ID. You can find the ID for any symbol in the
[Symbol Gallery](/ginetex/gallery/) — hover over a card to see its description, and the code is shown below each symbol.

IDs describe the symbol, e.g. `wash-30`, `tumble-dry-low` or `do-not-iron`.

## TypeScript

All packages ship full TypeScript types. The `core` package exports the `CareSymbol` type and
`CareSymbolCategory` union if you need them:

```ts
import type { CareSymbol, CareSymbolCategory } from '@ginetex/core';
```
