## Why GINETEX Care Symbols?

The GINETEX care symbols, standardised as ISO 3758, are the washing, bleaching, drying, ironing
and professional-care pictograms printed on textile care labels. This library packages all 43
symbols as accessible, fully typed components ready to drop into any project.

<CardGrid>
  <Card title="React & Vue 3" icon="puzzle">
    Named components and a `SymbolById` helper for dynamic rendering. Tree-shakeable — only the
    symbols you import end up in your bundle.
  </Card>
  <Card title="Web Components" icon="laptop">
    Framework-agnostic Custom Elements. Works with Angular, Svelte, plain HTML — anywhere.
  </Card>
  <Card title="CSS Sprite" icon="seti:css">
    Zero JavaScript option. Display any symbol with a single class and no JS runtime.
  </Card>
  <Card title="Accessible by default" icon="approve-check-circle">
    Every component renders with `role="img"`, `aria-labelledby`, `<title>`, and `<desc>` inside
    the SVG.
  </Card>
</CardGrid>

## Categories

| Category | Symbols | Base shape | Covers |
| -------- | ------- | ---------- | ------ |
| `washing` | 9 | Wash tub | Maximum temperature, mild / very mild process, hand wash |
| `bleaching` | 5 | Triangle | Any bleach, oxygen / non-chlorine only, do not bleach |
| `drying` | 12 | Square | Tumble drying (dots = heat) and natural drying (line, flat, drip, shade) |
| `ironing` | 5 | Iron | Maximum soleplate temperature (dots = heat) |
| `professional-care` | 12 | Circle | Professional dry cleaning (P, F solvents) and wet cleaning (W) |
