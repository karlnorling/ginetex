---
title: "@ginetex/assets"
description: Raw SVG, PNG, and WebP asset files for laundry care symbols at multiple resolutions.
---

## Installation

```sh
npm install @ginetex/assets
```

## Directory layout

Assets are organised by category and symbol code under the `assets/` directory:

```
assets/
├── washing/
│   └── wash-30/
│       ├── wash-30.svg
│       ├── wash-30_240x240.png
│       ├── wash-30_512x512.png
│       ├── wash-30_768x768.png
│       ├── wash-30_1024x1024.png
│       ├── wash-30_2048x2048.png
│       ├── wash-30_240x240.jpg
│       ├── wash-30_240x240.webp
│       └── ...
├── bleaching/
├── drying/
├── ironing/
└── professional-care/
```

## Available sizes

| Size    | Formats      |
|---------|--------------|
| SVG     | `.svg`       |
| 240 px  | `.png`, `.webp` |
| 512 px  | `.png`, `.webp` |
| 768 px  | `.png`, `.webp` |
| 1024 px | `.png`, `.webp` |
| 2048 px | `.png`, `.webp` |

## Import by path

Reference a specific asset directly in your bundler:

```ts
import wash30Svg from '@ginetex/assets/assets/washing/wash-30/wash-30.svg';
import wash30Png from '@ginetex/assets/assets/washing/wash-30/wash-30_512x512.png';
```

## Resolve paths via the core API

Use `@ginetex/core` to look up asset paths programmatically without hardcoding directory structure:

```ts
import { getSymbol } from '@ginetex/core';

const symbol = getSymbol('wash-30');

// SVG path
const svgPath = symbol.assets.svg;
// → 'washing/wash-30/wash-30.svg'

// PNG at a specific size
const png512 = symbol.assets.png[512];
// → 'washing/wash-30/wash-30_512x512.png'

// WebP at a specific size
const webp240 = symbol.assets.webp[240];
// → 'washing/wash-30/wash-30_240x240.webp'
```

Combine with a base URL for use in `<img>` tags:

```ts
const baseUrl = 'https://cdn.example.com/ginetex/assets/';
const src = baseUrl + symbol.assets.png[512];
```
