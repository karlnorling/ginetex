# @ginetex/elements

Accessible Web Components (Custom Elements) for the **GINETEX / ISO 3758** laundry care symbols — framework-agnostic, zero runtime dependencies.

[![npm](https://img.shields.io/npm/v/@ginetex/elements)](https://www.npmjs.com/package/@ginetex/elements)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/karlnorling/ginetex/blob/main/LICENSE)

---

## Installation

```sh
npm install @ginetex/elements
# or
yarn add @ginetex/elements
```

---

## Usage

### Register all elements

```ts
import { defineCustomElements } from '@ginetex/elements';
defineCustomElements();
```

Then use the elements in HTML:

```html
<!-- Generic element — render any symbol by ID -->
<ginetex-symbol symbol-id="wash-30" width="64"></ginetex-symbol>

<!-- Named elements (generated by yarn generate) -->
<ginetex-wash-30 width="64"></ginetex-wash-30>
<ginetex-do-not-tumble-dry width="64"></ginetex-do-not-tumble-dry>
```

### Custom prefix

Avoid tag-name conflicts with other libraries by passing a custom prefix:

```ts
defineCustomElements('care');
// Registers: care-symbol, care-wash-30, care-do-not-tumble-dry, …
```

## Attributes

All elements and `<ginetex-symbol>` accept the same attributes:

| Attribute     | Default              | Description                                                  |
| ------------- | -------------------- | ------------------------------------------------------------ |
| `symbol-id`   | —                    | Symbol slug ID (`<ginetex-symbol>` only), e.g. `"wash-30"`   |
| `title`       | Symbol name          | Accessible title (`<title>` inside SVG)                      |
| `description` | Symbol description   | Accessible description (`<desc>` inside SVG)                 |
| `aria-label`  | —                    | Labels the `<svg>` directly instead of via title/description |
| `width`       | SVG intrinsic width  | Forwarded to the `<svg>` width attribute                     |
| `height`      | SVG intrinsic height | Forwarded to the `<svg>` height attribute                    |

All attributes are reactive — changing them re-renders the SVG.

## Framework usage

### React

```tsx
// React treats unknown elements as HTML. Add a JSX type declaration if needed.
declare namespace JSX {
  interface IntrinsicElements {
    'ginetex-symbol': React.HTMLAttributes<HTMLElement> & {
      'symbol-id'?: string;
      width?: string | number;
      height?: string | number;
    };
  }
}

<ginetex-symbol symbol-id="wash-30" width="64" />;
```

### Vue 3

```vue
<template>
  <ginetex-symbol symbol-id="wash-30" width="64" />
</template>
```

## Accessibility

Each element renders with `role="img"` and `aria-labelledby` pointing to a `<title>` and `<desc>` injected inside the SVG. An `aria-label` attribute on the element labels the `<svg>` directly instead. Ids are unique per element, so the same symbol can appear any number of times on a page. The host element gets `display: contents` so it is transparent to layout.
