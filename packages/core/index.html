ID format

Section titled “ID format”

Symbol IDs are stable kebab-case codes. The symbols have no official numbering, so the codes are assigned in bin/scrape.ts and never change once published. A few examples:

  • wash-30, wash-30-mild, hand-wash, do-not-wash
  • bleach-non-chlorine, do-not-bleach
  • tumble-dry-low, line-dry-in-shade, dry-flat
  • iron-medium, do-not-iron
  • dry-clean-pce-mild, wet-clean, do-not-dry-clean

The full list is in the Symbol Gallery.
