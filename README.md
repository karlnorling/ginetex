# GINETEX Care Symbols

Accessible, framework-agnostic packages for the **GINETEX / ISO 3758** laundry care symbols — React components, Vue components, Web Components (Custom Elements), CSS sprite, SVG sprite, and static image assets.

## Symbol categories

The 43 symbols follow the five care treatments of a care label, in label order:

| Category            | Base shape | Symbols | Example IDs                                           |
| ------------------- | ---------- | ------- | ----------------------------------------------------- |
| `washing`           | Wash tub   | 9       | `wash-30`, `wash-30-mild`, `hand-wash`, `do-not-wash` |
| `bleaching`         | Triangle   | 5       | `bleach`, `bleach-non-chlorine`, `do-not-bleach`      |
| `drying`            | Square     | 12      | `tumble-dry-low`, `line-dry`, `dry-flat`, `drip-dry`  |
| `ironing`           | Iron       | 5       | `iron-low`, `iron-medium`, `iron-high`, `do-not-iron` |
| `professional-care` | Circle     | 12      | `dry-clean-pce`, `wet-clean-mild`, `do-not-dry-clean` |

Symbol IDs are stable kebab-case codes assigned in [`bin/scrape.ts`](bin/scrape.ts) (the
symbols have no official numbering). Dots on tumble-dry and iron symbols mean temperature
level; one bar under a symbol means a mild process, two bars a very mild one.

## Quick start

### React

```sh
npm install @ginetex/react
```

```tsx
import { SymbolById } from '@ginetex/react';

export default function CareLabel() {
  return <SymbolById id="wash-30" width={120} />;
}
```

Individual named components are generated by `yarn generate` after running `yarn update`:

```tsx
import { Wash30, DoNotTumbleDry } from '@ginetex/react';

<Wash30 width={64} />
<DoNotTumbleDry width={64} title="Do not tumble dry" />
```

### Vue 3

```sh
npm install @ginetex/vue
```

```vue
<script setup>
import { SymbolById } from '@ginetex/vue';
</script>
<template>
  <SymbolById id="wash-30" :width="120" />
</template>
```

### Web Components

```sh
npm install @ginetex/elements
```

```ts
import { defineCustomElements } from '@ginetex/elements';
defineCustomElements();
```

```html
<ginetex-symbol symbol-id="wash-30" width="64"></ginetex-symbol>
<ginetex-wash-30 width="64"></ginetex-wash-30>
```

### CSS sprite

```sh
npm install @ginetex/css
```

```js
import '@ginetex/css/sprite.css';
```

```html
<span
  class="ginetex-wash-30"
  style="display:inline-block;width:64px;height:64px"
  role="img"
  aria-label="Wash at or below 30 °C"
></span>
```

### SVG sprite

```sh
npm install @ginetex/sprite
```

```html
<svg width="64" height="64" role="img" aria-label="Wash at or below 30 °C">
  <title>Wash at or below 30 °C</title>
  <use href="/path/to/sprite.svg#wash-30" />
</svg>
```

### Programmatic API

```ts
import { getAllSymbols, getSymbol, getSymbolsByCategory } from '@ginetex/core';

const allSymbols = getAllSymbols();
const symbol = getSymbol('wash-30');
const drying = getSymbolsByCategory('drying');
```

## Development

### Prerequisites

- Node.js >= 24 (see `.nvmrc`)
- Yarn 4 (`corepack enable`)

### Setup

```sh
git clone https://github.com/karlnorling/ginetex.git
cd ginetex
yarn install
```

### Populate symbol data

Scrape Wikipedia, download SVGs from Wikimedia Commons, and generate all source files:

```sh
yarn update
```

This runs three steps in sequence:

1. **scrape** — fetches symbol codes, names, and image URLs from the [Laundry symbol](https://en.wikipedia.org/wiki/Laundry_symbol) Wikipedia article
2. **create-assets** — downloads SVGs and converts them to PNG, JPG, and WebP at 240/512/768/1024/2048 px
3. **generate** — generates TypeScript source for all packages

### Compile

```sh
yarn compile
```

### Test

```sh
yarn test
```

### Storybook

The published Storybook lives at <https://karlnorling.github.io/ginetex/storybook/>. To run it locally:

```sh
yarn storybook
```
